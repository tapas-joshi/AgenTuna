# Agent-prefixed multilingual names: configuration, settings, arrangement

Research date: **2026-11-04**. This is name screening, not trademark, company-name
or legal clearance. Nothing below establishes that a name, domain, package or
handle is available, registrable or safe to launch. No product was installed,
renamed or reconfigured; no file outside this report was changed.

## Bottom line

Five candidates were carried forward after the exact-string checks used here; none is cleared. Ranking weighs
dictionary fit, length, exact-string cleanliness and near-name crowding; it is
not a legal risk score.

| Rank | Candidate | Language and word | Literal dictionary sense | Main trade-off |
| --- | --- | --- | --- | --- |
| 1 | **AgentSkipan** | Old Norse/Icelandic *skipan* | order, arrangement, disposition | Cleanest exact profile; the first four letters spell "skip". |
| 2 | **AgentAyar** | Turkish *ayar* | setting, adjustment, standard | Shortest; "Ayar" search is dominated by Ayar Labs. |
| 3 | **AgentSettei** | Japanese 設定 *settei* | setting, configuration, establishment | Most literal; generic term and a PyPI config loader already use *settei*. |
| 4 | **AgentTarteeb** | Arabic ترتيب *tartīb* | arrangement, ordering | Exact checks clean, but tarteeb.ai is an adjacent AI product. |
| 5 | **AgentVinyas** | Hindi विन्यास *vinyās* | configuration, arrangement, layout | Excellent meaning; very crowded near AgentVine and Agentivas. |

**Recommended next step:** advance **AgentSkipan** and **AgentAyar** to a
professional clearance search. Keep **AgentSettei** as the literal fallback.
**AgentTarteeb** and **AgentVinyas** are memorable but sit in crowded near-name
spaces; do not adopt either without targeted clearance.

## The candidates

### 1. AgentSkipan

- **Word:** Old Norse and Icelandic *skipan*, feminine noun.
- **Meaning:** order, arrangement, disposition; also due order and, in modern
  usage, an order or command. Cleasby–Vigfusson's examples are military and
  ceremonial: drawing up troops, the order of a procession.
- **Pronunciation:** approximately **SKIP-an**, first-syllable stress.
- **Why it works:** two syllables, six letters, a hard consonant frame, and an
  exact arrangement/order meaning. It sounds like a tool, not a metaphor.
- **Main risk:** the first four letters spell "skip", which can suggest omission
  or bypassing. For a configuration manager, that is an unwanted secondary
  reading. The word is also obscure outside Norse/Icelandic circles, and it is a
  standard word in Icelandic, so search noise is likely.
- **Exact checks:** no exact product surfaced for `"AgentSkipan"` or
  `"Agent Skipan"`; the closest result was a Ukrainian B2B freight marketplace
  project called [SKIPAN](https://freelancehunt.com/en/project/development-the-b2b-freight-transportation/1656531.html),
  which is a different spelling context and sector. Exact npm, PyPI and crates.io
  names `agentskipan` and `agent-skipan` returned HTTP 404. GitHub repository
  name search returned `total_count: 0`; the `github.com/agentskipan` handle
  returned 404. `agentskipan.com` returned RDAP 404; no A records resolved for
  `.com`, `.dev`, `.io` or `.app`. Bare `skipan` was 404 on npm, PyPI and
  crates.io.
- **Read:** strongest exact-string and packaging profile of the five. The
  "skip" substring is the reason to test it with real users before committing.

### 2. AgentAyar

- **Word:** Turkish *ayar*, noun.
- **Meaning:** the state of a device being set to do its required work; a
  standard or adjustment; the fineness of precious metal; the proper measure in
  a task. Cambridge's learner dictionary maps the control-position sense of
  *setting* to "ayar, derece". TDK labels the etymology Arabic *ʿiyār*.
- **Pronunciation:** approximately **ah-YAR**, with the stress on the second
  syllable, not "AY-ar".
- **Why it works:** four letters, two syllables, and an exact setting/adjustment
  meaning. It also carries the idea of calibration and standard, which suits a
  tool that keeps agent configurations in a known state.
- **Main risk:** [Ayar Labs](https://ayarlabs.com/), an optical I/O chipmaker
  with a large AI-industry profile, dominates searches for "Ayar". The sectors
  differ, but an AI-adjacent buyer may already associate the word with that
  company. English speakers may also stress the first syllable.
- **Exact checks:** no exact product surfaced for `"AgentAyar"` or
  `"Agent Ayar"`; the returned results were Ayar Labs pages and a personal
  surname. Exact `agentayar` and `agent-ayar` were 404 on npm, PyPI and
  crates.io. GitHub repository name search returned `total_count: 0`; the
  `github.com/agentayar` handle returned 404. `agentayar.com` returned RDAP 404;
  no A records resolved for `.com`, `.dev`, `.io` or `.app`. Bare PyPI
  [`ayar`](https://pypi.org/project/ayar/) exists, but it is a spike-sorting
  assay tool, not a configuration product; bare `ayar` was 404 on npm and
  crates.io.
- **Read:** best short option. The Ayar Labs association is the main brand-search
  cost, not a direct product collision.

### 3. AgentSettei

- **Word:** Japanese 設定, read *settei*.
- **Meaning:** establishing or deciding a matter or condition; in law, creating
  a right. The first sense is the ordinary word for a setting or configuration.
- **Pronunciation:** approximately **SET-tay**; Japanese セッテイ has a long final
  vowel. English speakers may reduce it to "settee".
- **Why it works:** it starts with "set", is two English syllables, and is
  semantically transparent to anyone who knows Japanese. It reads as a tool that
  sets things up.
- **Main risk:** it is a generic Japanese word, not a distinctive coinage. The
  bare name is already occupied in package registries: PyPI
  [`settei`](https://pypi.org/project/settei/) is described as a "Configuration
  loader from a TOML file", a direct semantic neighbour, and the npm `settei`
  record exists with no published versions. In anime and manga, *settei* also
  means model sheets and production reference materials ([設定資料](https://www.content-eater.com/ja/glossary/settei-shiryo)),
  so the word carries a second, unrelated fandom meaning. [Setti.ai](https://setti.ai/) and
  [Setai Agents](https://setai-agents.gitbook.io/setai-agents) are near names in
  agent tooling.
- **Exact checks:** no exact product surfaced for `"AgentSettei"` or
  `"Agent Settei"`; the returned results were Setti.ai and Setai Agents. Exact
  `agentsettei` and `agent-settei` were 404 on npm, PyPI and crates.io. GitHub
  repository name search returned `total_count: 0`; the
  `github.com/agentsettei` handle returned 404. `agentsettei.com` returned RDAP
  404; no A records resolved for `.com`, `.dev`, `.io` or `.app`.
- **Read:** the most literal choice, but the bare suffix is already doing
  configuration work on PyPI. If the product ships a Python package, use the full
  `agentsettei` name, not `settei`.

### 4. AgentTarteeb

- **Word:** Arabic ترتيب, *tartīb*, verbal noun of form II *rattaba*.
- **Meaning:** arrangement, ordering, setting in order, classification. Lane's
  entry for the verb is "he set things in order, disposed them regularly,
  arranged them, or classified them." Rekhta's Urdu dictionary gives the same
  arrangement/order sense ([Rekhta](https://rekhtadictionary.com/meaning-of-tartiib-1?lang=ur)).
- **Pronunciation:** approximately **tar-TEEB**; the Arabic ط is emphatic, which
  English "t" does not capture.
- **Why it works:** two syllables, a strong consonant frame, and an exact
  arrangement/order meaning. It is distinctive in English and easy to spell after
  one hearing.
- **Main risk:** [tarteeb.ai](https://www.tarteeb.ai/en) already sells agency
  management with AI agents for clients, projects, tasks and invoices. That is an
  adjacent product category, not just a name collision. There are also
  [tarteeb.app](https://www.tarteeb.app/) (an Islamic app) and
  [Tarateeb](https://www.tarateeb.com/en) (manufacturing software). Because it is
  an ordinary Arabic and Urdu word, search results will include non-brand uses in
  those markets.
- **Exact checks:** no exact product surfaced for `"AgentTarteeb"` or
  `"Agent Tarteeb"`; the returned results were ByteDance's Agent TARS and a
  [Tarteeb branding agency](https://www.linkedin.com/company/tarteebagency).
  Exact `agenttarteeb` and `agent-tarteeb` were 404 on
  npm, PyPI and crates.io. GitHub repository name search returned `total_count:
  0`; the `github.com/agenttarteeb` handle returned 404. `agenttarteeb.com`
  returned RDAP 404; no A records resolved for `.com`, `.dev`, `.io` or `.app`.
  Bare `tarteeb` was 404 on npm, PyPI and crates.io.
- **Read:** memorable and semantically exact, but tarteeb.ai makes the name look
  like a variant of an existing AI product. Targeted clearance is required.

### 5. AgentVinyas

- **Word:** Hindi विन्यास, *vinyās*, masculine noun, from Sanskrit.
- **Meaning:** configuration, arrangement, layout, formation, composition;
  placing something in its proper place; setting or fixing. Collins translates
  the word directly as "configuration" and "arrangement". Hindwi gives the
  placement and neat-arrangement senses.
- **Pronunciation:** approximately **vin-YAAS**. The Sanskrit citation form
  *vinyāsa* would be "vin-YAA-sa"; the Hindi form drops the final -a. "AgentVinyas"
  matches the Hindi spelling, not the full Sanskrit transliteration.
- **Why it works:** six letters, two syllables, and the most direct
  "configuration" gloss in the set. It is distinctive in English and has a
  pleasant vowel pattern.
- **Main risk:** the near-name space is crowded. [AgentVine](https://agentvine.com/)
  is an ad network for AI agents; [Agentivas](https://www.agentivas.com/) is an AI
  automation startup; [Vinyas Innovative Technologies](https://vinyasit.com/) is an
  Indian electronics manufacturer; PyPI
  [`vinagent`](https://pypi.org/project/vinagent/) is an agent package; and
  Vinyasa is also the name of an athletic yoga style
  ([Merriam-Webster](https://www.merriam-webster.com/dictionary/vinyasa)).
  "AgentVinyas" sits phonetically between
  AgentVine and Agentivas, which is the worst possible neighbourhood for spoken
  recall.
- **Exact checks:** no exact product surfaced for `"AgentVinyas"` or
  `"Agent Vinyas"`; the returned results were Dvina's agents documentation,
  `vinagent` on PyPI and Vinsi.ai. Exact `agentvinyas` and `agent-vinyas` were
  404 on npm, PyPI and crates.io. GitHub repository name search returned
  `total_count: 0`; the `github.com/agentvinyas` handle returned 404.
  `agentvinyas.com` returned RDAP 404; no A records resolved for `.com`, `.dev`,
  `.io` or `.app`. Bare `vinyas` and `vinyasa` were 404 on npm, PyPI and
  crates.io.
- **Read:** best semantics, worst phonetic crowding. Do not adopt without a
  clearance search that specifically covers AgentVine, Agentivas and Vinyas
  Innovative Technologies.

## Screened out

### AgentShikumi

- **Meaning:** Japanese 仕組み, *shikumi*, is "structure, mechanism, scheme";
  Kotobank's third sense includes an arrangement of content in theatre or
  fiction. It is adjacent to configuration, not a direct synonym.
- **Why it was dropped:** crates.io
  [`shikumi`](https://crates.io/crates/shikumi) is already described as
  "config discovery, hot-reload, and ArcSwap store for Nix-managed desktop apps"
  — a direct functional collision in the same Rust ecosystem this project uses.
  PyPI [`shikumi`](https://pypi.org/project/shikumi/) also exists. There is a
  [SHIKUMI DESIGN](https://www.shikumi.co.jp/en/) company (Springin'), a
  [株式会社シクミ](https://shikumi-co.jp/) doing AI workflow automation for real
  estate, and [Shikigami](https://shikigami.dev/), an AI coding-agent runner.
- **Read:** reject for this product. The name is memorable, but the bare suffix
  already names a configuration crate and the near-name field includes AI coding
  agents.

### AgentTataan

- **Why it was dropped:** the Indonesian *tataan* was considered as an
  arrangement/layout candidate, but the KBBI mirror returned no entry for
  *tataan*; the meaning could not be verified to the standard used here. It is
  not carried forward.

## Method and limits

Every candidate was checked with:

| Check | Endpoint or command | Signal used |
| --- | --- | --- |
| npm exact | `https://registry.npmjs.org/<pkg>` for `agent<word>` and `agent-<word>` | HTTP 200 = package or name record exists |
| PyPI exact | `https://pypi.org/pypi/<pkg>/json` for `agent<word>` and `agent-<word>` | HTTP 200 |
| crates.io exact | `https://crates.io/api/v1/crates/<pkg>` for `agent-<word>` and `agent_<word>` | HTTP 200 |
| GitHub repository | `https://api.github.com/search/repositories?q=<Name>+in:name` | `total_count` and top hits |
| GitHub handle | `https://github.com/<name>` | 404 = no user or organisation page |
| `.com` registry | `https://rdap.verisign.com/com/v1/domain/<domain>` | 404 = no registration record |
| DNS | `dig +short A <name>.<tld>` for `.com`, `.dev`, `.io`, `.app` | An A record means something is published |
| Web | exact-phrase searches for `"Agent<Word>"` and `"Agent <Word>"` | Indexed product, post or repository |

Not searched: USPTO, EUIPO, UKIPO or any other trademark register; company
registries; app stores; social handles; paid clearance databases; registries
other than npm, PyPI and crates.io. `.dev`, `.io` and `.app` registration status
was not resolved through their registries: only DNS A records were checked, and a
missing A record is not evidence of availability. GitHub's search covers
repository names only, not code, README text or private repositories. Web search
results are point-in-time and can omit unindexed products.

A clean row means "nothing found in the sources checked", never "available".
